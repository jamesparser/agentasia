# GPUCloud rollout plan

AgentAsia currently offers browser-local WebGPU models as the free mode. GPUCloud is recorded as the future hosted free-compute route but is not enabled until its API, limits, acceptable-use requirements, and commercial terms are known.

Before enabling GPUCloud:

- obtain documented API credentials and model-routing terms;
- define free-user rate, token, vision, TTS, and concurrency limits;
- add server-side account/authentication and abuse controls;
- meter usage before turning on subscriptions;
- keep GPUCloud credentials server-only.

Paid plans must be enforced by server-side entitlements, not by frontend UI state.
